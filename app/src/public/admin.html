Information

Bienvenue dans l'outil de questionnaire de maturité agile/produit. Cette page centralise les fonctions d'administration :

  • Import du référentiel Excel
  • Création et paramétrage des sessions
  • Gestion des rôles proposés aux répondants
  • Import des participants et création des emails invitation / rappel
  • Consultation des résultats et export PPT

Entrez l'identifiant d'une session pour activer les écrans liés à cette session et ouvrir directement :

Ouvrir le questionnaire Ouvrir les résultats Ouvrir le pilotage
Session active La liste reprend les sessions déjà créées pour ouvrir directement les écrans associés.

Le choix ci-dessus remplit automatiquement les liens « répondant », « résultats » et « pilotage ».

1. Importer le référentiel (fichier Excel)

1 onglet = 1 pilier. Choisissez comment l'import traite la version précédente du référentiel. Dans tous les cas, les nouvelles sessions utilisent la nouvelle grille.

Que faire de la version précédente ?

2. Créer une session

Pré-rempli avec un message par défaut (qui rappelle le caractère nominatif des réponses). Adaptez-le au contexte de l'équipe ; il s'applique à cette session.

Tout est coché par défaut. Décochez un pilier entier ou des questions précises pour les retirer de cette session.

Importez d'abord un référentiel.

3. Inviter les participants par email

Liste des participants (CSV ou Excel) : colonne A = email, colonne B = nom (facultatif). Un nouvel import remplace la liste existante pour cette session.

Modèles d'email

Les modèles sont pré-remplis et peuvent être modifiés avant envoi. Ils sont sauvegardés localement pour réutilisation.

L'invitation s'adresse à toute la liste ; le rappel ne cible que les invités n'ayant pas encore soumis leur questionnaire (rapprochement par email).
